# Safety and Fail-Safe Design

This is a prototype and is not a certified hearing-protection device.

The fast limiter path is intentionally independent of AI classification.

## Failure Cases to Test
- AI model unavailable
- Accelerator failure
- Software crash
- Watchdog timeout
- Power interruption
- Excessive output
- Startup/shutdown transients
- Thermal overload
- EMI/interference

Actual hearing-protection limits and certification requirements must be established through qualified safety testing.
